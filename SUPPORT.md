# Getting help

PrismTeX is a young project maintained in spare time, so there is no guaranteed response time.

1. **Check the docs.** [README.md](README.md) covers setup, [docs/configuration.md](docs/configuration.md) every setting, and [docs/compile.md](docs/compile.md) how compiling works.
2. **Search the [issues](https://github.com/nvmaditya/OpenPrism/issues)**, open and closed. Someone may have hit the same problem.
3. **Something broken?** Open a [bug report](https://github.com/nvmaditya/OpenPrism/issues/new?template=bug.yml). Include your operating system, your TeX distribution, and the steps that show the problem.
4. **An idea, or a question the docs don't answer?** Open a [feature request](https://github.com/nvmaditya/OpenPrism/issues/new?template=feature.yml). A question usually means a doc is missing, and we treat it that way.

For a security problem, do not open an issue: follow [SECURITY.md](SECURITY.md).
