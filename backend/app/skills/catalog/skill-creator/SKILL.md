# skill-creator

The `skill-creator` skill guides creation and revision of reusable skills. A skill packages specialized knowledge, a repeatable workflow, or a tool integration.

Use it when designing a new `SKILL.md`, refining an existing skill's instructions, or structuring supporting references and assets.

## Workflow

1. Pick a skill name (a-z, 0-9, hyphens).
2. Write YAML frontmatter: `name`, `description` (with trigger phrases).
3. Write an actionable body (steps, constraints, examples).
4. Install into skill-home or project `.prism/skills/` via the installer API.
