# Roadmap

PrismTeX is being rebuilt in five phases. Each phase after the first ends in a release. The reasons behind each phase are in the [revamp design](docs/design/2026-11-24-revamp-design.md) (§9), and the agent is specified in the [agent design](docs/design/2026-11-24-agent-design.md).

| Phase | Name | Release | Status |
|---|---|---|---|
| 0 | Clean slate | none | In review |
| 1 | Agent core | v0.1.0, the first public release | Planned |
| 2 | Real editor | v0.2.0 | Planned |
| 3 | Trust layer | v0.3.0 | Planned |
| 4 | Self-host | v0.4.0, then v1.0.0 | Planned |

## Phase 0: Clean slate (in review)

Safe to run, honest, licensed and renamed, with CI green. The old agent is retired so the new one can be built on a clean base. The [Phase 0 spec](docs/plans/2026-11-25-phase-0-clean-slate.md) has the details.

Exit criteria:

- The LangChain agent, the skills subsystem, PNG previews and the tool runner are gone, and their routes return 404.
- The API binds 127.0.0.1, checks `Host` and `Origin`, and refuses to bind beyond loopback without an access token.
- Compiles run through hardened latexmk with build output outside the project folder, and the TeX lane's escape tests pass on TeX Live.
- The paper, résumé and blank templates compile with no undefined citations or references.
- Project state lives outside project folders, and old `.prism/` folders are migrated.
- The project is named PrismTeX and licensed under Apache-2.0, with the community files in place.
- CI is green on every lane (backend on Ubuntu and Windows, TeX, frontend), and `ci-ok` is the required check.

## Phase 1: Agent core (v0.1.0)

A new agent whose changes are reviewed before they reach the paper.

Exit criteria:

- A turn engine we own, with two profiles: agentic for frontier models and guided for small local models. Providers: Ollama, Anthropic, any OpenAI-compatible endpoint, and a fake one for tests.
- A turn never writes the project folder. Its changes arrive as a proposal that the user accepts or rejects hunk by hunk.
- Each proposal is compiled in a scratch copy and compared with the pre-turn diagnostics, with up to two repair rounds. The outcome line is written by the host from what actually happened.
- Threads, traces, and a git shadow history with checkpoints, diff and restore.
- A minimal agent panel in the current UI, with streaming, Stop and diff review.
- ZIP import of OpenAI Prism and Overleaf exports.
- An eval harness with a replay lane in CI, and published results on qwen3 4B: no control characters in any trial, question tasks change nothing, and the guided profile passes at least 5 of the 9 probe tasks in all 3 trials.
- A Claude acceptance run under the cost guard, which stops at $9.50.
- v0.1.0 tagged and released, with notes generated by git-cliff.

## Phase 2: Real editor (v0.2.0)

Exit criteria:

- CodeMirror 6 with LaTeX highlighting, completion of commands, labels, citation keys and paths, diagnostics in the gutter, and tabs.
- A pdf.js viewer with find and zoom, and SyncTeX in both directions.
- A docked agent panel with threads, and review in a merge view with per-hunk accept and reject.
- History and settings screens, and first-run provider setup.
- Resizable panes, with a tabbed layout below 1024 px.
- End-to-end tests for buffer safety and SyncTeX.

## Phase 3: Trust layer (v0.3.0)

Exit criteria:

- Citation checks against Crossref, arXiv, OpenAlex and Semantic Scholar, off until the user turns them on, and a citation audit report for a project.
- References the agent adds are verified or flagged.
- One-click "fix this error" from a diagnostic.
- A provenance record of accepted AI changes, and an AI-use statement generated from it.
- The citation audit passes on the fixture bibliographies.

## Phase 4: Self-host (v0.4.0, then v1.0.0)

Exit criteria:

- A Docker image and a compose file, with optional Ollama, built for several architectures by CI when a tag is pushed.
- Docker runs under the same rule as today: an access token whenever it listens beyond loopback.
- Data-layout migrations at startup, with a backup taken first, and project export.
- A docs site, if the docs have outgrown the `docs/` folder.
- v1.0.0 follows a stabilization pass and one final Claude regression run.

PrismTeX is an independent project. It is not affiliated with or endorsed by OpenAI.
